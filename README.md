# security-shield-service
The security-shield-service is an encapsulated Nuxt 4/5 layer providing full-stack anti-spam protection. It integrates an off-screen honeypot, bot challenges, and self-hosted heuristic/NLP text filtering into a Git-locked dependency, while automating abuse reporting and IP threat logging directly to sender domains.

| Capability                                   | Recommended owner                        |
| -------------------------------------------- | ---------------------------------------- |
| Honeypot and bot challenges                  | `security-shield-service`                |
| Spam detection, heuristics and NLP filtering | `security-shield-service`                |
| Threat scoring and submission decisions      | `security-shield-service`                |
| Abuse report generation and validation       | `security-shield-service`                |
